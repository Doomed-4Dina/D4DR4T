# D4DR4T

🖥️ D4DR4T – Feature Requests

D4DR4T is a PowerShell & Node.js-based Remote Administration Tool (RAT) designed for security research and controlled system administration. It is continuously evolving, and I’m looking for new feature ideas to enhance its capabilities.

	⚠️ Disclaimer: This tool is for ethical security research and authorized system administration only. Unauthorized use is strictly prohibited.

🚀 Current Features

D4DR4T already includes a wide range of functionalities, including but not limited to:

🔧 System & Device Control
	•	File management (upload/download, execution)
	•	Volume control
	•	Screenshots & monitor/webcam detection
	•	Text-to-Speech (TTS)
	•	Custom script execution
	•	Clipboard management
	•	Process list retrieval
	•	Drive mapping

💻 System Manipulation & Persistence
	•	Wallpaper control
	•	Power options (shutdown, restart, hibernate, etc.)
	•	Bootloop & Windows kill techniques
	•	VM detection & evasion
	•	Secondary AnyDesk RAT installation

🔍 Data Collection & Monitoring
	•	Password collection
	•	Browser history & cookies extraction
	•	Discord token collection
	•	Telegram session extraction
	•	Gaming session tracking (Steam, Uplay, Epic)
	•	Device information retrieval

🎭 Interaction & Psychological Impact
	•	Message popups
	•	Jumpscares

🌐 Automation & Online Integration
	•	Facebook, Twitter, and Throne automation
